# Programa-Extensão
# Equipe Responsável: Renato Henrique, Luis Felipe Aizza Araujo e Renan Rodrigues

# Resumo:

# Este projeto de extensão teve como foco a imersão da comunidade acadêmica no ecossistema de inovação tecnológica e a troca de experiências entre pares. A iniciativa consistiu na participação em um evento no Inteli (Instituto de Tecnologia e Liderança) com foco na tecnologia Blockchain, complementada por uma entrevista realizada com outro participante que também acompanhou a palestra.

# Por meio desse bate-papo, foi possível captar diferentes perspectivas, impressões e insights sobre como os conceitos de descentralização, segurança de dados e impactos no mercado foram absorvidos pelo público. O projeto cumpriu seu papel extensionista ao promover o diálogo, registrar a percepção coletiva sobre novas tecnologias e conectar o aprendizado compartilhado com a realidade da sociedade.
